Premiers pas vers l'utilisation de git et GitHub.


/*********************************************************************************************************/
Some useful commands:

To add all the changes made to the current branch:
git add .

To commit the changes to the branch:
git commit -m 'description of the commit'

To check the history of the different commits:
git log

To check out the different existing branches:
git branch

To return to a previous state/branch:
git checkout "ash code"
where "ash code" is the code that can be retrieved from the list displayed after the command git branch.

To check out different information on the git and GitHub setups on the local machine:
git config --list

To check out the different ssh key on the local machine:
ls -al ~/.ssh

To copy some stuff about a given ssh key present on the local machine:
clip.exe < ~/.ssh/id_ed25519.pub
